# ScholarPrompt Hub

A focused self-directed learning hub containing 69 free courses from Harvard, Yale, and MIT.

## Stack

- React
- Vite
- lucide-react
- Plain CSS

## Features

- 69-course catalog
- Search by course or university
- Harvard / Yale / MIT filters
- Saved courses persisted in browser local storage
- One-click course links
- Copy course URL
- Responsive dark interface

## Run locally

```bash
npm install
npm run dev
```

Build for production with `npm run build`.

## Note

The catalog links are maintained as direct university course-page references. Course availability and URLs can change over time, so individual links should be verified when a course is selected for study.
